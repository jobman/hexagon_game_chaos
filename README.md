# Hexagon Game

Это гексагональная стратегическая игра, разработанная на Python с использованием библиотеки Pygame.

Особенностью проекта является попытка реализовать сложное, "хаотическое" поведение игровой системы и юнитов без использования прямого рандома. Вместо этого, поведение определяется взаимодействием множества детерминированных правил и условий, что приводит к непредсказуемым, но логически вытекающим результатам.
